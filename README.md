# Adhesiv_flow
This project aims to solve a Non-Newtonian fluid flow through a syringe. 
It may sound simple, but viscosity is no longer constant, making the solution a lot more complicated.

I came up with this project with the goal of qualifying myself to work on the adhesivs and selants industry :) So who knowns if it will be relavant for someone. I had fun with it though.

The project was build step by step into different code files, it the ideas could be slowly developed and validated. 

If you are interested in this project, I recommend reading the report first, where the theory is developed and the project strucutre is covered.

If you just want to see the final result, run the finite_vol_6_SIMPLE_shearthinning.c, You can just compile with the parameters you wish and run. 
Please read the warining given once you run the program. It gives an insight whether if the final result will be correct or not.
